

\# Employee Management System



A web-based employee management application built with Python, Flask, and MySQL.



\## Features

\- Admin login and authentication

\- Employee management (CRUD)

\- Department management

\- Employee search and pagination

\- REST API

\- Automated tests



\## Technologies

\- Python

\- Flask

\- MySQL

\- SQLAlchemy

\- HTML, CSS, Bootstrap



\## Setup

1\. Clone this repository.

2\. Create and activate a Python virtual environment.

3\. Install dependencies using `pip install -r requirements.txt`.

4\. Create a MySQL database named `employee\_management`.

5\. Create a local `.env` file with your own `SECRET\_KEY` and `DATABASE\_URL`.

6\. Initialize the database using `python -m flask --app run:app init-db`.

7\. Create an admin account using `python -m flask --app run:app create-admin`.

8\. Start the server using `python -m flask --app run:app run --debug`.
